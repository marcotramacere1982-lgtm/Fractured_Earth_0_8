# Fractured Earth

Companion app for the *Fractured Earth* tabletop RPG: the rulebook, the character builder and a smart character sheet.

**Open it:** https://marcotramacere1982-lgtm.github.io/Fractured_Earth_0_8/

- Works in any modern browser, on a phone, tablet or PC. English and Italian.
- Characters you make are saved in your own browser on that device. Use **Export** on the sheet to keep a copy as a file, and **Import file** on the start screen to load it back on another device.
- Nothing you do here is sent anywhere.
